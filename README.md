### Project Description
**Overthinking as a service** is an AI-powered chatbot that turns your everyday conversations into overthinking with five unique personalities. Choose between Bestie, Savage Baddie, Detective, Delulu, and Doomer — each offering their own chaotic perspective on your situation.


### The Problem (that doesn't exist)
You had one tiny thought. Then you analyzed the wording, timing, punctuation, and possible meanings for the next three hours. OverthinkAI solves the completely unnecessary problem of not having enough people to overthink with you.

### The Solution (that nobody asked for)
We built OverthinkAI — an AI chatbot that takes your tiny thought and gives it five completely different ways to overthink it. Choose your personality: Bestie, Savage Baddie, Detective, Delulu, or Doomer — because apparently one perspective was never enough.

## Technical Details
### Technologies/Components Used
For Software:
 - Languages used: TypeScript, JavaScript, HTML, CSS
 - Frameworks used: React, Vite, Node.js
 - Libraries used: Google GenAI SDK, dotenv
 - Tools used: Google AI Studio, GitHub, Visual Studio Code, npm

### Implementation
- Built a web-based AI chatbot using React, TypeScript, and Vite.
- Integrated the Google Gemini API to generate conversational responses.
- Implemented five distinct AI personalities: Bestie, Savage Baddie, Detective, Delulu, and Doomer.
- Added contextual conversation handling so the AI can respond naturally based on the user's situation and previous messages.
- Created a dark, modern UI focused on making the overthinking experience fun, interactive, and easy to use.
# Installation
- Clone the repository : git clone gtihub.com/kmrot-twest/overthinking-as-a-service
- Navigate to the project folder cd overthinking-as-a-service
- Install dependencies: npm install
- Create a .env file and add your Gemini API key GEMINI_API_KEY=your_api_key_here


# Run
- npm run dev

- After the server starts, open: http://localhost:3000
